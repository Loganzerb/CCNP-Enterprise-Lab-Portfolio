# Convergence

The lab compared timer-driven 802.1D behavior with Rapid PVST+ convergence. Classic STP observations focused on the listening and learning phases governed by the configured 15-second Forward Delay. Rapid PVST+ used point-to-point proposal/agreement behavior where eligible and synchronized alternate paths without waiting through the full classic transition.

The summary capture provides the retained post-lab operational state. Exact stopwatch captures were not retained, so no synthetic timing transcript is included.
