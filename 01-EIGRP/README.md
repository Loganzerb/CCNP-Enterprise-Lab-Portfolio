# EIGRP Lab

## Overview

This section documents the Enhanced Interior Gateway Routing Protocol (EIGRP) portion of my CCNP Enterprise lab environment.

The EIGRP lab was built using Cisco Modeling Labs (CML) to practice enterprise routing design, verification, failure testing, and troubleshooting.

The focus of this lab was understanding not only configuration, but how EIGRP behaves during network changes and failures.

## Topics Covered

- Classic EIGRP configuration
- Named EIGRP configuration
- Neighbor formation and authentication
- Diffusing Update Algorithm (DUAL)
- Feasible Distance (FD)
- Reported Distance (RD)
- Successor and Feasible Successor paths
- Route summarization
- Stub routing
- Route filtering
- Failure testing and convergence analysis

## Lab Structure

Additional documentation is organized into:

- `configs` - sanitized Cisco IOS configurations
- `verification` - verification commands and outputs
- `troubleshooting` - failure scenarios and analysis
