# EIGRP Configurations

This directory contains sanitized Cisco IOS configurations from the EIGRP AS 100 lab environment.

The configurations document the routing design implemented in the CCNP Enterprise lab, including:

- Router interfaces and addressing
- EIGRP AS 100 configuration
- Router IDs
- Authentication examples
- Route summarization
- Stub routing
- Route filtering
- Redistribution controls

## Sanitization

Before publication, configurations were cleaned to remove:

- CML/YAML metadata
- Device-specific platform information
- Unnecessary default configuration
- Authentication secrets

Authentication values have been replaced with placeholders while preserving the configuration design.

## Included Routers

- R1-CORE
- R2-DIST-A
- R3-DIST-B
- R4-BRANCH
- R5-REMOTE
