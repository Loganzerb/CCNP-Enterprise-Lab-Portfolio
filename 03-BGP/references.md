# Technical references

These references support protocol interpretation. The portfolio's configurations and captured output remain the evidence for what happened in this lab.

- [Cisco — Select BGP Best-path Algorithm](https://www.cisco.com/c/en/us/support/docs/ip/border-gateway-protocol-bgp/13753-25.html): next-hop eligibility and the ordered comparison of candidate paths.
- [Cisco — Troubleshoot Border Gateway Protocol Basic Issues](https://www.cisco.com/c/en/us/support/docs/ip/border-gateway-protocol-bgp/218027-troubleshoot-border-gateway-protocol-bas.html): session diagnosis, next-hop reachability, and route installation.
- [Cisco — Next-Hop Mismatch and BGP Inactive Routes](https://www.cisco.com/c/en/us/support/docs/ip/border-gateway-protocol-bgp/116146-config-bgp-next-hop-00.html): the distinction between BGP best-path selection and IP routing-table installation.
- [RFC 1997 — BGP Communities Attribute](https://www.rfc-editor.org/rfc/rfc1997.html): community representation and the meaning of `NO_EXPORT`.
- [RFC 4271 — Border Gateway Protocol 4](https://www.rfc-editor.org/rfc/rfc4271.html): session messages, Bad Peer AS errors, and next-hop handling on a shared subnet.
