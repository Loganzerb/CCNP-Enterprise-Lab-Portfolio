# CCNP Enterprise Lab Portfolio

## Overview

This repository documents my journey building and troubleshooting enterprise networking environments while preparing for the Cisco Certified Network Professional (CCNP) Enterprise certification.

The labs are built primarily using Cisco Modeling Labs (CML) and focus on real-world network engineering concepts including routing protocols, redundancy, failure analysis, and design validation.

The goal of these projects is not only to configure technologies, but to understand:
- Why the network behaves the way it does
- How to verify expected behavior
- How to troubleshoot failures systematically
- How design decisions impact scalability and resiliency


# Lab Portfolio

## 01 - EIGRP

Topics covered:

- Classic and named Enhanced Interior Gateway Routing Protocol (EIGRP)
- Neighbor formation and authentication
- Diffusing Update Algorithm (DUAL)
- Feasible Distance and Reported Distance
- Successor and Feasible Successor paths
- Query behavior and Stuck-In-Active troubleshooting
- Route summarization
- Stub routing
- Filtering and default route control


## 02 - OSPF

Topics covered:

- Multi-area Open Shortest Path First (OSPF)
- Area Border Router (ABR) design
- Designated Router (DR) and Backup Designated Router (BDR) elections
- Broadcast and point-to-point network types
- Link-State Advertisement (LSA) analysis
- Not-So-Stubby Area (NSSA) design
- External route types
- Authentication
- Filtering and summarization


## 03 - Redistribution

Topics covered:

- EIGRP and OSPF mutual redistribution
- Route tagging
- Redistribution loop prevention
- Seed metrics
- Administrative Distance considerations
- Routing Information Base (RIB) behavior
- Failure testing and convergence analysis


## 04 - BGP

Topics covered:

- External and internal Border Gateway Protocol (BGP)
- BGP neighbor relationships
- Best path selection
- Weight
- Local Preference
- Autonomous System Path manipulation
- Multi-Exit Discriminator (MED)
- Route maps and prefix lists
- Communities
- Route aggregation
- VRF-Lite
- IPv6 BGP


## 05 - Spanning Tree Protocol

Topics planned:

- Spanning Tree Protocol (STP)
- Rapid Spanning Tree Protocol (RSTP)
- Per-VLAN Spanning Tree Plus (PVST+)
- Rapid PVST+
- Multiple Spanning Tree Protocol (MSTP)
- Layer 2 troubleshooting scenarios
